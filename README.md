# BettrTrade

Bis Version 2.1.0 hieß das Programm „Trendfolge“. Wer es schon installiert hat, bekommt den neuen Namen als ganz normales Update. Verknüpfungen werden dabei umbenannt, Einstellungen, Merkliste, Depot und Alarme bleiben erhalten.

Windows-Programm für Krypto, Aktien, ETFs, Indizes, Rohstoffe und Devisen: Märkte, Merkliste, Scanner, Analyse, Depot und Alarme. Im Mittelpunkt steht die 50-Tage-Linie für BTC, ETH und SOL (Long über der Linie, Short darunter).

**Keine Anlageberatung.** Das Programm zeigt Zahlen und Tendenzen, keine Kauf- oder Verkaufsempfehlungen.

## Installieren

1. Die neueste Version öffnen: **[Releases → Latest](https://github.com/SkzFPS/trendfolge-download/releases/latest)**.
2. Unten bei *Assets* auf **BettrTrade-Setup-….exe** klicken und herunterladen. Fragt der Browser, ob die Datei behalten werden soll, auf **Behalten** klicken.
3. Die heruntergeladene Datei doppelt anklicken.
4. Beim ersten Mal warnt Windows mit „Der Computer wurde durch Windows geschützt“, weil das Programm nicht signiert ist. Auf **Weitere Informationen** und dann **Trotzdem ausführen** klicken.
5. Fertig. BettrTrade installiert sich in ein paar Sekunden und startet. Eine Verknüpfung liegt auf dem Desktop und im Startmenü. Administratorrechte braucht es nicht.

## Updates

Kommen von selbst. Das Programm schaut beim Start und alle 4 Stunden nach einer neuen Version und lädt sie im Hintergrund herunter. Ist sie fertig, steht oben in der Titelleiste **Update … · Neu starten**. Ein Klick darauf, und BettrTrade ist nach ein paar Sekunden mit der neuen Version wieder da. Wer nicht klickt, bekommt das Update beim nächsten Beenden.

Von Hand nachsehen: **Einstellungen → Updates → Nach Updates suchen**.

Einstellungen, Merkliste, Depot und Alarme bleiben bei jedem Update erhalten.

## Deinstallieren

Windows-Einstellungen → **Apps** → **Installierte Apps** → bei **BettrTrade** auf die drei Punkte → **Deinstallieren**.

Deine Einstellungen, Merkliste, Depot und Alarme bleiben danach im Ordner `%APPDATA%\Trendfolge` liegen (der Ordner heißt noch nach dem alten Namen), falls du das Programm später wieder installierst. Wer alles loswerden will, löscht diesen Ordner zusätzlich.
